# SweatsEnhancements 0.0.1 — public source/rebuild notes

This source archive corresponds to the installable SweatsEnhancements 0.0.1 JAR (Forge 1.8.9, Java 8). From its root, run `bash build.sh build`; the script obtains JDK 8 and Gradle 6.9.4 and Gradle resolves declared dependencies. The installable result is in `build/libs/`. Source, build scripts and included assets are provided together so recipients can inspect, modify and rebuild the LGPL-covered adaptations. This distribution does not prohibit reverse engineering to debug those modifications.

The retained dungeon-map HUD (`src/main/java/com/sweatsenhancements/feature/DungeonMapHud.java`) adapts NEF's selection of a received map and Minecraft's own map renderer; the custom map grid, world room detector, puzzle solvers, puzzle logger, room datasets and map-room sprites were removed from this release. These removed components are not in this public source or JAR. The SweatsEnhancements pet card uses a vanilla item icon; externally sourced pet portraits were removed pending artwork-rights review.

Other LGPL-covered portions include NEF dungeon visuals and slayer adaptations, and NEU smooth teleport adaptations. See the bundled `THIRD-PARTY-NEF-NOTICE.txt`, `THIRD-PARTY-NEU-NOTICE.txt`, corresponding license texts, and `META-INF/third-party/` for dependency and original-source attributions. Third-party components retain their own terms.
