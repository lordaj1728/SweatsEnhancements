# Install SweatsEnhancements 0.0.1

For Minecraft 1.8.9 Forge, place `SweatsEnhancements-0.0.1.jar` in the instance's `mods/` folder. Remove the previous Fakepixel Enhancements JAR from that folder before restarting (otherwise both mods load). Java 8 is the target runtime.

Open the config menu with P or `/se menu` (also `/sweatsenhancements menu`). HUD editor: H. Probe dump: I. Configure gameplay shortcuts in the mod's own config menu.

Existing `config/fpe/fpe.properties`, protected-item rules and chat filters are copied on first launch into `config/sweatsenhancements/`; old files are left untouched. If a new destination file already exists, migration does not overwrite it. Keep a backup of your Minecraft config folder before updating.
